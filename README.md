# TODO Group Community Presentations

Set of presentations about Open Source Program Offices (OSPOs).

## TODO Group Overview Presentation

A TODO Group overview presentation is available via [Google Docs](https://docs.google.com/presentation/d/1p4dhx0Dg8fZDO8yzp7nWC2r5WHyVH-jjSQM59lkKLdo/edit?usp=sharing). The content introduces OSPO industry challenges, the OSPO definition, TODO Group's mission, and key resources to improve OSPO education and adoption.

We encourage contributors to submit a pull request if they would like to provide translations of this presentation.

## OSPO Presentations

This space gathers talks given at conferences related to Open Source Program Offices. If you gave a presentation about OSPOs or any related topic, and would like it linked in this repo, please make sure to:

* Use the Apache v2.0 or CC-BY license so the content can be easily shared and reused
* Submit a PR with the title, conference event, and link to resources (slides and video)
