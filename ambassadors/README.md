# TODO Group Ambassadors - Presentation Resources

Welcome! This folder provides presentation templates and resources for **TODO Group Ambassadors** to use when giving talks about TODO Group and Open Source Program Offices (OSPOs) in their regions.

## 🎯 Purpose

As a TODO Group Ambassador, you represent the community in your region. These resources are designed to help you:

- Introduce TODO Group to new audiences
- Explain what an OSPO is and why it matters
- Share best practices for open source management
- Grow the local OSPO community
