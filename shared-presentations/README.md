# Shared OSPO Presentations

This space gathers talks given at conferences and events related to Open Source Program Offices. These presentations are shared by the community and cover topics such as OSPO strategy, governance, compliance, metrics, and best practices.

## How to Contribute

If you gave a presentation about OSPOs or any related topic, and would like it linked in this repo, please:

1. Use the **Apache v2.0** or **CC-BY** license so the content can be easily shared and reused
2. Submit a PR with the title, speaker(s), conference, and link to resources (slides and/or video)
